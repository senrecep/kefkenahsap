# Quickstart Guide

This guide provides a quick way to test the main features of the Kefken Ahşap Dekorasyon website.

## Scenario 1: Public User

1.  **Navigate to the website:** Open your browser and go to the website's URL.
2.  **View the project list:** On the homepage, you should see a list of projects. Click on the "Our Projects" link in the navigation to see the full list.
3.  **View a single project:** Click on any project from the list to see its details. You should see the project's story, images, and other information.

## Scenario 2: Admin User

1.  **Navigate to the admin login page:** Go to `/admin/login`.
2.  **Log in:** Enter your admin credentials to log in.
3.  **Go to the admin dashboard:** After logging in, you will be redirected to the admin dashboard.
4.  **Create a new project:** Click on the "New Project" button. Fill out the form with the project details and upload images. You can choose to add a watermark to the images.
5.  **Save the project:** Click the "Save" button.
6.  **Verify the new project:** Go back to the public website and check if the new project is now visible in the project list.
